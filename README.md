# Tablet Reminder

An Android app that starts tablet reminders when you tap **I ate food**,
rings every few minutes (at your media volume) until you mark your tablets as taken,
and keeps a history of each meal.

## Get the app on your phone

1. Upload every file and folder from this project into a new GitHub repository
   (including the `.github` folder).
2. Open the **Actions** tab. The "Build app" run starts by itself and takes about 5 minutes.
3. When it shows a green tick, open the **Releases** section on the repository's main page.
4. On your phone, open the newest release and tap **TabletReminder.apk** to download it.
5. Open the downloaded file and allow "Install unknown apps" when Android asks.

To build again after a change, edit any file on GitHub and commit it; a new release appears.

## First time you open the app

- Allow notifications when asked.
- Add your medicines on the Medicines tab.
- On the Settings tab, under "Make sure it rings", tap **Fix** on anything listed.
- Tap "Test the alarm sound" and set your media volume.
